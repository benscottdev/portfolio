Ben Scott - Portfolio

A modern, interactive portfolio website built with React, Three.js, and GSAP.

Features

  • 3D interactive orb with shape morphing
  • Smooth scroll animations with GSAP ScrollTrigger
  • Physics-based skills visualization using Matter.js
  • Responsive design
  • Real-time Sydney timezone display

Tech Stack

  • React 19
  • Vite
  • Three.js (3D graphics)
  • GSAP (animations)
  • Matter.js (physics engine)
  • SCSS (styling)

Development

npm install
npm run dev

Build

npm run build
